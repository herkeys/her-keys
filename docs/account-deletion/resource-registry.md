# Deletion resource registry

Source: verified Staging catalog snapshot in `staging-schema-census.json`; integration entry ad72ccd. This is an inventory, not a deletion certification. No Storage buckets were present in Staging at census time. Production needs a separately approved read-only census before deployment.

Whole-household cleanup is permitted only when no other adult profile shares any of the account's households. The approved shared policy independently deletes exclusive private leaves, quarantines exact ambiguous resources and opens seven-day operator cases. No automatic transfer occurs. Unknown public application tables fail the worker closed. Full resource-fixture coverage remains a separate certification gate.

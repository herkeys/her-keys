# HK-FEATURE-04 — missing global primitives register (Addendum O)

Findings from Feature 04 only. Sibling registers (Features 01/02/03) are **not** consulted or reconciled here; the integration
wave compares them. Allowed types: `UI` · `COPY` · `DOMAIN-PROJECTION` · `ACTION-MAP` · `OTHER`.
Nothing below was fixed in shared foundation — each row records what Feature 04 did *locally* instead.

| MP-01 | DOMAIN-PROJECTION | A System lifecycle: status (active / paused / archived) and a retire/delete semantic | `HouseholdSystem` (`src/domain/state.ts:188`); sync `ALLOWED_OPS.system` = create/update only | No status field; no delete path in cloud or local ("this wave does not invent removal").

## Confirmed NOT missing (checked, not assumed)

- **Work-domain classification** (ADDENDUM D's STOP condition): `HouseholdCategory.systemRole === 'work'` already exists as an explicit, non-inferred starter category (`cat-work`), seeded with `scope: 'professional'`. F10 did not need to invent or STOP on this.
- **Generic relationship primitive** (ADDENDUM A): `Dependency` + `TypedRef` already existed and needed only one new endpoint kind (`'opportunity'`) — no `CareerOpportunityLink` table was created.
- **Owner-private scope** (ADDENDUM L): the `personal` scope every other foundation kind already uses is real, RLS-enforced, owner-only. No new scope was invented.
- **Additive schema pattern** (ADDENDUM AC): the `FOUNDATION_SPECS` manifest + `gen-foundation-sql.mjs` generator already existed as the sanctioned way to add a 19th foundation kind; no competing storage architecture was needed.
